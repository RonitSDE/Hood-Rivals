# Outpost Rivals v1.5.1 — execution report

Run date: 2026-10-27. Test target: ZIP source, Node 24, local Express/Vite build, isolated SQLite database and local EVM Ganache tests. The local server was stopped after the run.

## Passed
- Every source file in v1.5.0 input ZIP matched its SHA-256 manifest. Fresh npm ci, production frontend build, Solidity compilation and all 16 automated tests passed.
- Local server returned HTTP 200 for `/healthz`, `/readyz`, `/`, and the isometric island asset. Unauthenticated bootstrap was denied.
- Three independent guests were created. A practice match earned no progression. Two participants joined a room, sealed orders, completed the match, and got a hash-verified replay and one saved campaign entry each. The third user's campaign remained empty.
- One daily ranked match produced a second entry. A repeat ranked attempt was denied. Both entries and the profile's played count survived server restart in SQLite.
- Unconfigured checkout returned an error rather than granting an item. Automated local EVM checkout tests covered signature, expiry, payer, asset, allowance, event and replay boundaries.
- 1,200 deterministic simulations reported zero rule invariant violations. This is no evidence of human retention or balance.
- A clean production-only npm install and dependency audit reported 0 known vulnerabilities at this run date. Development Ganache dependencies may produce separate audit findings and are excluded from the runtime image.

## Corrected in v1.5.1
The wallet picker and deployment instructions had claimed optional WalletConnect QR setup even though its connector was removed in v1.5.0. The picker, docs and environment example now accurately say injected browser wallets and mobile wallet app browsers are supported, and QR pairing is unavailable. Removed unused QR package. Linux clean-install lockfile records were normalized again after the dependency change.

## Not exercised
- Actual wallet extension and mobile app-browser interaction, visual/accessibility inspection in a real browser, live Robinhood Chain transactions, deployed contracts, token payment and receipt recovery, public URL/TLS/reverse proxy, Docker image runtime, load, or independent smart-contract audit.
- The cloud browser could not reach the isolated local test server. Static build and HTTP asset responses passed, but this is not a visual UI acceptance test.

## Release decision
Suitable for a restricted free beta after deployed-host smoke checks. Paid Robinhood checkout and public mainnet launch remain gated on a real wallet/chain purchase, receipt and recovery verification, mobile UI review, and an independent contract/security review.
