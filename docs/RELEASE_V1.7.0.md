# Hood Rivals v1.7.0 — selected artwork and Robinhood testnet handoff

## Included

- The team's selected transparent PNG is copied byte-for-byte to `public/hood-rivals-logo.png` and displayed in navigation, loader, island masthead, browser/social metadata and exported battle card. Older draft SVGs and token icon were removed. The default unsigned token metadata plan points to this selected image.
- React/Three.js player UI, standalone local island, Express/SQLite authoritative match API, wallet account linking, signed cosmetic orders and `OutpostStore` Solidity contract are packaged together. An unconfigured payment path remains disabled.
- `npm run testnet:smoke -- --broadcast` is an operator-only **real testnet** end-to-end check: wallet challenge, captain onboarding, server-signed stablecoin quote, allowance, contract purchase, confirmed receipt, inventory entitlement and duplicate purchase rejection. It prints an explorer URL. This command requires a configured HTTPS app, deployed contracts and a funded isolated test wallet; it cannot run against a visual preview.

## Deploy on Robinhood Chain testnet (46630)

1. With Node 24 run `npm ci --ignore-scripts`, `npm test`, `npm run build`, `npm run contracts:compile`, `npm run simulate`, and `npm run economics`. Copy `.env.example` to a secret `.env` and configure a durable DB, exact public HTTPS `APP_ORIGIN`, reverse proxy trust count and `NODE_ENV=production`. Set `BUILD_SHA` to the deployed source identifier. Serve **one** app replica behind TLS, preserving SQLite storage.
2. Verify the current official RPC/chain details. Fund a testnet deployer with ETH. Set a separate owner address (prefer multisig), treasury address and a dedicated quote signer address. Run `npm run contracts:deploy -- --testnet-mocks` as a dry run, then `npm run contracts:deploy -- --testnet-mocks --broadcast`. Save the deployment JSON and actual transaction/explorer links. The mock stable (`tUSDG`) and mock token (`tRIVAL`) are **test fixtures**, not real cash or canonical launch assets. They mint to the deployer. Transfer the amount needed for one purchase to a separate test buyer; fund that buyer with test ETH.
3. Set `STORE_ADDRESS`, `TOKEN_ADDRESS`, `STABLE_ADDRESS`, decimals, `TREASURY_ADDRESS` and `QUOTE_SIGNER_PRIVATE_KEY` in the protected server environment. Remove `DEPLOYER_PRIVATE_KEY` and any smoke buyer key from the runtime environment. Leave `TOKEN_UNITS_PER_DOLLAR` blank unless testing token-denominated quotes. Restart and run `npm run preflight` from a secure operator shell. Keep the app's store address exactly aligned with the deployed contract.
4. From a separate operator shell set `TEST_BUYER_PRIVATE_KEY` to the funded test buyer. With the HTTPS app live and the rest of the app config loaded, run `npm run testnet:smoke -- --broadcast`. This **spends test assets**. It refuses mainnet, an unfunded wallet, stale/mismatched config and previously owned cosmetics. Record its explorer URL; use a new test wallet or `TESTNET_SMOKE_SKU` for a repeat run.
5. In real wallets on desktop and mobile, verify connect, sign, captain setup, free practice, saved match/replay, Armory payment, pending-hash recovery after reload, cosmetic equip and rejection on wrong chain/account. Test on the public deployment, not the sample-data static preview. Check `/healthz` and `/readyz`, backend logs, DB backup/restore, Caddy/TLS and device performance.

## Boundaries

No keys, deployed addresses, funded wallets, live testnet transaction or public production app are included. The source and local EVM tests demonstrate implementation, not a live Robinhood receipt or third-party security audit. The preview is a private UI illustration with mocked API data. The island's 15 local rule agents are browser-only; server-owned six-round matches are separate. `RIVAL` pricing is a configured merchant quantity, never an oracle or promise of token price appreciation. Do not promote public paid checkout or mainnet until a real explorer receipt, inventory entitlement and independent review have been recorded.
