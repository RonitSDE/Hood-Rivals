# Hood Rivals v2.1.0 — guided journey

This builds on the v2.0.0 testnet handoff. Read `docs/RELEASE_V2.0.0.md` for contract deployment, ownership, persistence, checkout and safety gates.

The first wallet-linked captain sees a five-chapter Field Guide. It teaches the island, wood/stone/food gathering, tactical supply posts, the six-round goal, Human/Agent control and the optional Agent ID. The guide has full captions and a user-triggered **Read aloud** button using browser speech synthesis. The separately controlled **Sound on/off** button saves a local preference and enables short synthesized navigation/round cues. Audio starts off. Browsers lacking voice support retain captions. No voice assets, external voice service or microphone access is used.

The main interface and isometric HUD use more saturated lime, cyan, electric blue and coral on dark blue. The home screen labels Human and Agent play, and exposes the island's resource loop. Agent playbooks (Balanced, Explorer, Fortifier, Diplomat) are free tactical styles with the same rules and no reward advantage. This release introduces no paid automation package or actual offline AFK farming: the island's gathered materials remain local, and Agent delegation chooses solo match orders only while that match is advanced. Do not market it as persistent offline yield. Do not tie real money or token emissions to local resource counters.

Before release, verify the five chapter sequence, narration start/stop, silent default, mute persistence, mobile layout and contrast in browsers; then follow the v2.0.0 live-wallet and testnet gates. The automated suite does not establish human retention, audio quality or final visual polish.
